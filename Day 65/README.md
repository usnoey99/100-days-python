## 🧠 Note

### Color Theory
Color theory helps designers choose and combine colors effectively.  

Important concepts include:
- Primary and secondary colors
- Color harmony
- Contrast
- Accent colors

Using appropriate colors can improve readability, visual hierarchy, and the overall appearance of a website.

### Typography
Typography is the design and arrangement of text.  

Important typography properties include:
- Font family
- Font size
- Font weight
- Line height
- Letter spacing

Good typography improves readability and helps users understand the structure of a webpage.

### User Interface (UI)
UI refers to the visual elements that users interact with on a website.  

Common UI elements include:
- Buttons
- Navigation menus
- Input fields
- Cards
- Icons

A good UI should be clear, consistent, and easy to use.

### User Experience (UX)
UX focuses on the overall experience a user has when interacting with a website or application.  

Good UX helps users:
- Find information easily
- Understand how to use the interface
- Complete tasks efficiently
- Navigate through the website smoothly

UI focuses mainly on how the interface looks and works, while UX focuses on how the user experiences the product.
