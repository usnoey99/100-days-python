## Day 18 - Turtle & the Graphical User Interface (GUI)

Exploring Python’s turtle module to build generative art and understand graphical programming concepts through code.

### Overview

This project focuses on learning the fundamentals of GUI-based drawing using Python. Through the turtle library, I practiced procedural drawing, randomness, and creative visual generation.

### 🐢 Topics Covered
- Turtle graphics basics and how to use documentation
- Drawing a square
- Drawing dashed lines
- Drawing various geometric shapes
- Implementing a random walk
- Using Python tuples and generating random RGB colors
- Creating a spirograph

### 🖼️ Hirst Painting Project
- Extracted RGB values from an image
- Recreated artwork using colored dots

### Note
Aliasing Modules:
import turtle as t
