## 🧠 Notes

### HTML Tables
Tables are used to organize data into rows and columns.

Basic structure:
```html
<table>
    <tr>
        <td>Row 1, Column 1</td>
        <td>Row 1, Column 2</td>
    </tr>
</table>
```
| Tag       | Purpose                     |
| --------- | --------------------------- |
| `<table>` | Creates a table             |
| `<tr>`    | Table row                   |
| `<td>`    | Table data cell             |
| `<th>`    | Table header cell           |
| `<thead>` | Groups table headers        |
| `<tbody>` | Groups table body content   |
| `<tfoot>` | Groups table footer content |

### HTML Forms
Forms allow users to enter and submit information.

- `<label>`: Labels describe the purpose of an input field.
- `<input>`: The <input> tag creates interactive form fields.
- `<textarea>`: The <input> tag creates interactive form fields.
