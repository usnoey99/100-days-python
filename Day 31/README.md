## Day 31 - Flash Card Program Project

---

### 📌 Overview
Built a flash card application as a capstone project to practice Python GUI development and data handling.

The program displays English words and automatically flips to show the German translation after a few seconds. It also tracks learned words by updating a CSV file.

---

### 📝 Tasks
- Create a user interface using Tkinter
- Display flash cards with English words
- Implement automatic card flipping after 5 seconds
- Show the German translation on the back of the card
- Update the word list when the user clicks the “right” button
- Store and manage vocabulary data using CSV files
